# 전투기 런 게임 PRD

## 1. 개요
- **게임명(가칭)**: 전투기 런 (Fighter Jet Run)
- **컨셉**: 크롬 디노런(공룡 점프 게임)의 구조를 차용하되, 캐릭터를 전투기로 변경하고 "점프"를 "공중 상승(비행)"으로 재해석한 무한 러너 게임
- **목표**: 장애물을 피하며 최대한 오래/멀리 비행하여 점수를 얻고, 상위 3위 순위표에 이름을 올리는 것

## 2. 핵심 차별점 (디노런 대비)
| 항목 | 디노런 | 전투기 런 |
|---|---|---|
| 캐릭터 | 공룡 | 전투기 (측면 뷰) |
| 조작 | 스페이스바로 점프(중력 낙하) | 스페이스바/터치로 상승, 떼면 하강 (중력 유지) |
| 배경 | 사막 | 하늘/구름 (선택: 낮/밤 전환) |
| 장애물 | 선인장, 새 | 대공포탄, 미사일, 새떼, 구름(장식용) 등 |

## 3. 핵심 게임 메커니즘
### 3.1 이동 및 조작
- 전투기는 화면 좌측 고정 위치에서 X축 이동 없이 Y축으로만 움직임
- 배경/장애물이 우→좌로 스크롤되며 진행 (속도는 시간에 따라 점진적 증가)
- **조작 방식**: 
  - 키 누름(스페이스바/터치 홀드) → 상승 (일정 가속도로 위로)
  - 키 뗌 → 중력에 의해 서서히 하강
  - 화면 상/하단 경계 존재 (천장/바닥 충돌 시 게임오버 또는 감속 처리, 초기엔 단순 충돌로 처리 권장)

### 3.2 장애물
- 상단/하단/중단에 랜덤하게 등장하는 장애물 (예: 대공포탄 - 아래→위, 새떼 - 직선 이동)
- 장애물 종류는 MVP에서는 1~2종으로 시작, 이후 확장

### 3.3 충돌 및 게임오버
- 전투기와 장애물의 충돌 판정(사각형 or 원형 히트박스)
- 충돌 시 게임오버 → 점수 기록 화면으로 전환

### 3.4 점수 시스템
- 기본: 생존 시간(또는 이동 거리) 기반 점수 자동 증가
- 장애물 회피 시 보너스 점수(선택 사항, MVP 이후 고려)
- 시간이 지날수록 스크롤 속도 증가 → 난이도 상승

## 4. 순위(리더보드) 시스템
- 게임오버 시 점수 저장 (닉네임 입력 또는 로그인된 사용자 이름 자동 반영 - 기존 인증 시스템 재사용 가능)
- **Firebase Firestore 연동**: `scores` 컬렉션에 `{name, score, timestamp}` 구조로 저장
- 상위 3위만 조회하여 게임오버 화면 및 메인 화면에 표시 (score 내림차순 정렬 + limit 3)
- 기존 보드게시판 프로젝트에서 이미 Firebase를 사용 중이므로 동일 프로젝트/DB에 컬렉션만 추가하는 방식으로 통합 가능

## 5. 화면 구성 (MVP 기준)
1. **시작 화면**: 게임 제목, 시작 버튼, 현재 TOP 3 순위 표시
2. **게임 플레이 화면**: 전투기, 장애물, 실시간 점수 표시
3. **게임오버 화면**: 최종 점수, TOP 3 순위(갱신 여부 강조), 재시작 버튼

## 6. 기술 스택 (제안)
- HTML5 Canvas + Vanilla JS (또는 기존 스티커보드 프로젝트와 동일하게 module 방식 app.js)
- Firebase Firestore (기존 프로젝트와 동일 DB 활용 가능)
- 애니메이션: requestAnimationFrame 기반 게임 루프

## 7. 개발 범위 (MVP)
- [ ] 전투기 상승/하강 조작 구현
- [ ] 장애물 1종 스폰 및 스크롤
- [ ] 충돌 판정 및 게임오버 처리
- [ ] 점수 카운트(생존 시간 기반)
- [ ] Firestore 연동 - 점수 저장 및 TOP 3 조회
- [ ] 시작/플레이/게임오버 화면 전환

## 8. 확장 아이디어 (MVP 이후)
- 장애물 종류 다양화 (미사일, 새떼, 구름 장애물 패턴화)
- 아이템(무적, 점수 2배 등) 추가
- 전투기 스킨 변경 기능
- 배경 낮/밤 전환 또는 스테이지 개념
- 효과음/BGM 추가

## 9. 확정 사항
- **닉네임**: 별도 입력 없이 기존 인증 시스템의 로그인된 사용자 이름을 그대로 사용
- **경계 충돌 처리**: 화면 상/하단 경계선에 닿으면 즉시 게임오버 (감속 → 가속 패널티를 거쳐 최종적으로 즉시 게임오버로 확정)
- **반응형**: 캔버스를 화면 크기에 맞춰 조절하고, 기준 해상도(800×400)로 환산해 어떤 기기에서도 체감 난이도와 점수 증가 속도가 동일하도록 처리
- **종횡비**: 데스크톱 2:1, 모바일 세로 1:1(기기별 난이도 차이를 없애기 위해 고정), 모바일 가로는 화면 높이에 맞춤
- **프레임 독립**: 고정 타임스텝(1/60초) + 누적자 방식으로 60/90/120Hz 어느 기기에서도 진행 속도가 동일
- **장애물 패턴**: 미리 정의된 패턴 세트가 아닌 완전 랜덤 생성 방식
- **난이도 곡선**: 1000점마다 1레벨, 12레벨에서 상한(그 이상 고정 → 실력으로 무한 지속 가능)
  - 속도는 레벨당 +0.5로 완만하게만 상승(4.0 → 10.0)
  - 스폰을 '프레임 간격'이 아닌 '진행 거리 간격'으로 관리해 속도와 무관하게 밀도를 통제
    (스폰 거리 360 → 144, 화면 내 평균 장애물 2.3개 → 6.8개)
  - Lv3부터 동시 2개, Lv6부터 동시 3개 스폰(Lv9부터 확률 상향)
  - 장애물 종류 해금: Lv2 유도 미사일, Lv4 대각선 포탄, Lv5 사인파 새떼,
    Lv7 대형 장애물(20%), Lv10 대형 30%·사인파 진폭 확대
- **공정성 가드레일**: 스폰 시 장애물 사이에 전투기 높이 2.6배 이상의 통로를 항상 보장하고,
  경계 여백 확보, 화면 내 장애물 8개 상한, 미사일은 웨이브당 1개 및 유도 속도 상한(항상 회피 가능)
