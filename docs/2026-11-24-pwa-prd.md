# PRD — PWA 전환 (홈 화면 설치 · 오프라인)

| 항목 | 내용 |
|------|------|
| 문서명 | 성능보드판 — PWA |
| 버전 | v1.0 |
| 작성일 | 2026-11-24 |
| 추가 파일 | `manifest.json`, `sw.js`, `pwa.js`, `assets/icon-*.png` |
| 수정 파일 | HTML 11개(머리글 추가), `index.html`(설치 메뉴) |
| 상태 | 구현 완료 |

---

## 1. 목표

1. 휴대폰 **홈 화면에 앱으로 설치**되고, 주소창 없이 전체 화면으로 열린다.
2. 통신이 끊겨도 **화면과 이미 본 페이지는 그대로 열린다**.
3. 두 번째 접속부터 **눈에 띄게 빨라진다**(파일을 기기에 저장해 두므로).

## 2. 구성

| 파일 | 역할 |
|------|------|
| `manifest.json` | 앱 이름·아이콘·시작 주소·전체 화면 설정. 바로가기 3개(공지/자재소모/사역표) |
| `sw.js` | 서비스 워커 — 파일 저장·오프라인 대응·버전 정리 |
| `pwa.js` | 서비스 워커 등록, 새 버전 알림 띠, 홈 화면 설치 안내 (모든 페이지에서 사용) |
| `assets/icon-*.png` | 192 / 512 / maskable 512 / apple-touch 180 |

- 모든 HTML 11개에 매니페스트·테마색·iOS 메타·`pwa.js`를 넣어, **어느 페이지로 들어와도** 설치·오프라인이 동작한다.
- 테마색은 기기 설정을 따라 밝은 모드 `#FFFFFF`, 어두운 모드 `#1F1F22` (헤더 색과 맞춤).

## 3. 저장 방식

| 대상 | 방식 | 이유 |
|------|------|------|
| 화면 이동(HTML) | **네트워크 우선**, 실패하면 저장본 | 접속 가능할 땐 항상 최신 화면 |
| CSS·JS·아이콘 | **저장본 먼저** 보여주고 뒤에서 갱신 | 즉시 열림 + 다음 접속에 최신 반영 |
| 글꼴·Firebase SDK | 저장본 먼저 | 바깥에서 받아오는 고정 파일 |
| **Firebase 실시간 데이터** | **저장 안 함** | 항상 실시간이어야 함 |
| **FT-200 PDF (13MB)** | **저장 안 함** | 용량이 커서 제외 |

## 4. 한계 (분명히 할 것)

- **오프라인에서는 글이 보이지 않는다.** 화면·메뉴·계산기 같은 도구는 열리지만, 공지·사역표·자재소모 같은 **데이터는 빈 상태**로 뜬다. 웹용 Firebase 실시간 DB는 기기에 데이터를 저장하는 기능이 없다. (균등분할 계산기, 드릴 조견표처럼 통신이 필요 없는 도구는 오프라인에서 그대로 쓸 수 있다.)
- **푸시 알림은 여전히 불가.** 설치형이 되어도 발송 서버가 없으면 알림을 보낼 수 없다.
- iOS는 `홈 화면에 추가`를 사용자가 직접 눌러야 한다(브라우저가 설치 버튼을 주지 않음). 더보기 메뉴의 `홈 화면에 앱 설치`를 누르면 방법을 안내한다.

## 5. ★ 배포할 때마다 할 일

**파일을 고쳐 올릴 때 `sw.js` 맨 위의 `VERSION`을 반드시 올린다.**

```js
const VERSION = "v20261124-1";   // → "v20261125-1" 처럼 변경
```

올리지 않으면 이미 설치한 사람 기기에 **예전 화면이 남는다**. 버전을 올리면 접속 시 화면 아래에 `새 버전이 있습니다 [새로고침]` 띠가 뜨고, 누르면 즉시 최신으로 바뀐다.

## 7. 설치 방법 (사용자 안내용)

- **안드로이드 크롬**: 접속 → 주소창 오른쪽 설치 아이콘, 또는 더보기 메뉴 → `홈 화면에 앱 설치`
- **아이폰 사파리**: 접속 → 아래 공유 단추(□↑) → `홈 화면에 추가` → `추가`
