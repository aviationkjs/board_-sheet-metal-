# 한셀 간트차트 만들기 가이드 (직접 수식 편집용)

| 항목 | 내용 |
|------|------|
| 문서명 | 학습 간트차트 — 한셀(한컴오피스 스프레드시트) 이식 가이드 |
| 버전 | v1.0 |
| 작성일 | 2026-08-20 |
| 대상 | 한셀에서 직접 수식을 입력해 만드는 사람 |
| 원본 | 웹판 `gantt.html` (보드 → 더보기 → 📅 학습 간트차트) |

---

## 이 문서의 목적

웹 간트차트의 **핵심 동작 — "한 과목 일정을 옮기면 뒤 과목이 전부 따라 움직인다"** 를 한셀에서 그대로 재현한다.

스프레드시트에는 블록 드래그가 없다. 대신 **시작일을 사람이 입력하지 않고 수식으로 계산**하게 만들면, 앞을 바꾸는 순간 뒤가 자동으로 다시 계산된다. 오히려 웹판보다 확실하다.

---

## 0. 시트 뼈대

새 시트에 아래처럼 입력한다.

| | A | B | C | D | E | F | G, H, I … |
|---|---|---|---|---|---|---|---|
| **1** | 기준 시작일 | `2026-08-20` | | | | | |
| **2** | | | | | | | |
| **3** | 과목 | 선행 | 간격 | 기간 | 시작일 | 종료일 | (달력) |
| **4** | 국어 | | 0 | 5 | 수식 | 수식 | |
| **5** | 수학 | 국어 | 0 | 7 | 수식 | 수식 | |
| **6** | 영어 | 수학 | 0 | 5 | 수식 | 수식 | |
| **7** | 사회 | 영어 | 0 | 4 | 수식 | 수식 | |
| **8** | 과학 | 사회 | 0 | 4 | 수식 | 수식 | |

- **B1은 날짜 서식**으로 지정한다 (셀 서식 → 날짜).
- 사람이 만지는 칸: **B열(선행) · C열(간격) · D열(기간) · B1(기준일)**
- 건드리면 안 되는 칸: **E열(시작일) · F열(종료일)** — 수식이다.

> **행 순서가 곧 의존 순서다.** 선행 과목은 **반드시 자기보다 위 행**에 있어야 한다. 이걸 지켜야 순환 참조가 나지 않는다.

---

## 1. 핵심 수식 두 개 ★

**E4에 입력** (시작일)

```
=IF($B4="",$B$1+$C4,INDEX($F$3:$F3,MATCH($B4,$A$3:$A3,0))+1+$C4)
```

**F4에 입력** (종료일)

```
=E4+D4-1
```

입력 후 **E4:F4를 선택해 8행까지 아래로 채우기**(드래그 또는 Ctrl+D).

### 이 수식이 전파를 만드는 원리

`$F$3:$F3` 이 부분이 핵심이다. 아래로 복사하면 자동으로 `$F$3:$F4`, `$F$3:$F5` … 로 늘어난다. 즉 각 행은 **자기보다 위에 있는 종료일만** 참조한다.

- 위를 참조하므로 → 앞이 바뀌면 뒤가 자동 재계산 = **전파**
- 위만 참조하므로 → **순환 참조가 원천적으로 불가능**

`$` 위치를 바꾸면 이 두 가지가 모두 깨진다. 수식을 그대로 복사해서 붙여넣을 것.

### 결과 확인

기준일이 `2026-08-20`이면 아래와 같이 나와야 한다.

| 과목 | 시작일 | 종료일 |
|---|---|---|
| 국어 | 2026-08-20 | 2026-08-24 |
| 수학 | 2026-08-25 | 2026-08-31 |
| 영어 | 2026-09-01 | 2026-09-05 |
| 사회 | 2026-09-06 | 2026-09-09 |
| 과학 | 2026-09-10 | 2026-09-13 |

## 2. 전파 테스트 — 반드시 해볼 것

여기까지 만들고 아래 4개를 직접 눌러본다. 이것이 이 문서의 목적인 **"한 번 옮기면 뒤가 따라온다"** 다.

| 만지는 셀 | 넣을 값 | 기대 결과 |
|---|---|---|
| **D4** (국어 기간) | 5 → **7** | 수학~과학 **전부 2일 뒤로** |
| **C4** (국어 간격) | 0 → **3** | 국어 포함 **전부 3일 뒤로** |
| **C5** (수학 간격) | 0 → **2** | 국어는 그대로, **영어~과학만 2일 뒤로** |
| **B1** (기준일) | +7일 | **5과목 전부 7일 뒤로** |

하나라도 어긋나면 수식의 `$` 위치부터 확인한다. 테스트가 끝나면 값을 원래대로 되돌린다.

### 웹판과의 대응 관계

| 웹판 | 한셀 |
|---|---|
| 블록을 오른쪽으로 드래그 | **간격(C열)** 을 늘림 |
| 블록 끝을 늘려 기간 조절 | **기간(D열)** 을 늘림 |
| 전체를 통째로 이동 | **기준일(B1)** 하나 수정 |
| 내부에 저장되던 lag | **간격(C열)** — 눈에 보이는 값이 됨 |

웹판에서 "왜 이만큼 벌어졌는지" 알 수 없던 lag가, 한셀에서는 셀 값으로 드러난다.

## 3. 달력 만들기

**G3에 입력**

```
=$B$1-3
```

**H3에 입력**

```
=G3+1
```

H3을 오른쪽으로 **BZ열 정도까지** 드래그한다 (약 90일치).

꾸미기:

- G3부터 끝까지 선택 → 셀 서식 → **날짜 → `d`** (일자만 표시)
- G열~BZ열 선택 → 열 너비 **2.5**
- 요일이 필요하면 한 줄 추가해 `=TEXT(G3,"aaa")`

## 4. 간트 막대 — 조건부 서식

**G4:BZ8을 선택한 상태**에서 시작한다. 선택 시작 셀이 **G4**인 것이 중요하다.

메뉴: **서식 → 조건부 서식 → 새 규칙 → 수식을 사용해 서식 지정**

아래 3개를 이 순서대로 등록한다.

**① 막대**

```
=AND(G$3>=$E4,G$3<=$F4)
```

→ 채우기: 파랑

**② 오늘**

```
=G$3=TODAY()
```

→ 테두리: 굵은 빨강 (채우기는 넣지 않는다 — 막대를 덮는다)

**③ 주말**

```
=WEEKDAY(G$3,2)>5
```

→ 채우기: 연회색

### `$` 위치 주의

- `G$3` = 열은 따라 움직이고 **행은 3행 고정** (날짜 줄)
- `$E4` = **E열 고정**, 행은 따라 움직임 (그 과목의 시작일)

이게 바뀌면 막대가 엉뚱한 곳에 그려진다.

### 과목별 색 구분

①번 대신 아래 5개를 등록한다.

```
=AND($A4="국어",G$3>=$E4,G$3<=$F4)    → 파랑
=AND($A4="수학",G$3>=$E4,G$3<=$F4)    → 주황
=AND($A4="영어",G$3>=$E4,G$3<=$F4)    → 초록
=AND($A4="사회",G$3>=$E4,G$3<=$F4)    → 보라
=AND($A4="과학",G$3>=$E4,G$3<=$F4)    → 청록
```

## 5. 주말 제외로 바꾸기 (선택)

토·일을 기간에서 빼려면 **E4와 F4 수식만 교체**하고 다시 아래로 채우기 한다.

**E4**

```
=IF($B4="",WORKDAY($B$1-1,1+$C4),WORKDAY(INDEX($F$3:$F3,MATCH($B4,$A$3:$A3,0)),1+$C4))
```

**F4**

```
=WORKDAY(E4-1,D4)
```

`WORKDAY(E4-1, D4)` 는 **E4를 첫째 날로 세어 D4번째 근무일**을 돌려준다.

> 한셀에서 `WORKDAY`가 없거나 다르게 동작하면 보조 열로 푸는 대안이 필요하다. 이 경우 그대로 두고 주말 포함 버전을 쓴다.

## 6. 사고 방지

### ① 수식 보호 (가장 중요)

E·F열 수식을 실수로 덮어쓰는 것이 이 방식의 유일한 큰 위험이다.

1. 전체 선택(Ctrl+A) → 셀 서식 → 보호 → **잠금 해제**
2. **E4:F8만 선택** → 셀 서식 → 보호 → **잠금 체크**
3. 도구 → **시트 보호**

사람이 만지는 칸(선행·간격·기간·기준일)만 열리고 계산 칸은 잠긴다.

### ② 선행 드롭다운

B4:B8 선택 → 데이터 → 유효성 검사 → 목록 → 원본 `=$A$4:$A$8`

### ③ 틀 고정

G4 셀 선택 → 보기 → **틀 고정**. 가로로 스크롤해도 과목 이름이 남는다.

## 7. 자주 나는 오류

| 증상 | 원인 | 해결 |
|---|---|---|
| `#N/A` | 선행 이름 오타, 또는 **선행이 아래 행에 있음** | 이름 일치 확인, 행 순서를 의존 순서대로 |
| 순환 참조 경고 | 선행이 자기보다 아래를 가리킴 | 행 순서 재배치 |
| 날짜가 `46000` 같은 숫자로 보임 | 셀 서식이 일반 | 셀 서식 → 날짜 |
| 막대가 안 그려짐 | 조건부 서식 `$` 위치, 또는 선택 시작 셀이 G4가 아님 | 규칙 삭제 후 **G4부터** 다시 선택해 등록 |
| 막대가 한 줄만 그려짐 | 적용 범위가 `G4:BZ4` | 적용 범위를 `G4:BZ8`로 수정 |
| **앞을 바꿔도 뒤가 안 움직임** | E열에 **수식이 아니라 날짜가 직접 입력**됨 | E4 수식 다시 넣고 아래로 채우기 |

마지막 항목이 가장 흔한 실수다. **E열·F열에는 절대 날짜를 직접 입력하지 않는다.** 일정을 옮길 때는 항상 **간격(C열) · 기간(D열) · 기준일(B1)** 만 만진다.

---

## 8. 과목 추가하기

1. 8행 아래(9행)에 새 행을 만든다.
2. A9에 과목명, B9에 선행 과목명(**반드시 위 행에 있는 이름**), C9 간격, D9 기간 입력
3. E8:F8을 복사해 E9:F9에 붙여넣기
4. 조건부 서식 적용 범위를 `G4:BZ9`로 넓힌다
5. 시트 보호를 걸어뒀다면 해제 후 작업하고 다시 건다

## 9. 한계 — 웹판과 나눠 쓰기

한셀 파일은 **동시 편집이 안 된다.** 여러 명이 각자 열어 고치면 마지막 저장이 앞사람 것을 덮어쓴다.

따라서 이렇게 쓰는 것을 권한다.

| 용도 | 도구 |
|---|---|
| 여러 명이 수시로 일정 조정 | **웹판** (`gantt.html`) — 실시간 공유, 되돌리기, 편집 잠금 |
| 인쇄 · 보고 · 배포 | **한셀** |

웹판에 CSV 내보내기를 붙이면 한셀로 넘기는 과정이 한 번의 클릭이 된다. 필요하면 추가한다.
