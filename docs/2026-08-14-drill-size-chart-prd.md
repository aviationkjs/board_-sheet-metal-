# PRD — 드릴 사이즈 표 (Number / Fraction Drill Chart)

| 항목 | 내용 |
|------|------|
| 문서명 | 성능기골 스티커 보드 — 드릴 사이즈 표 |
| 버전 | **v1.1 (최종 승인본)** |
| 작성일 | 2026-08-14 |
| 대상 파일 | `info.html` (전면 교체), `assets/photos/` (신규), `index.html` (메뉴 문구) |
| 인프라 | GitHub Pages 정적 호스팅, 서버 없음, DB 사용 안 함 |
| 상태 | **1단계 구현 완료** · 2단계(사진 콘텐츠)는 파일 수급 대기 |

---

## 1. 배경

`info.html` 은 Huck Gun · Fastener 관계표를 담고 있었으나, 현장에서 실제로 자주 찾는 것은 **드릴 사이즈**다. 판금 작업 중 "이 리벳엔 몇 번 드릴?", "1/8 인치가 몇 mm?" 를 확인하려면 매번 인쇄물이나 검색에 의존해야 했다.

이를 **번호 드릴 + 분수 드릴을 지름 순으로 통합한 표** 하나로 대체하고, 현장 메모·클리코 색·참고 사진을 항목별로 붙일 수 있게 한다.

## 2. 승인된 결정 사항

| # | 항목 | **결정** |
|---|------|----------|
| 1 | Letter drill (A~Z) | **넣지 않는다** |
| 2 | 추가 열의 성격 | **자유 메모** (형식 제약 없음) |
| 3 | 클리코 색 | 3/32=은색, 1/8=구리색, 5/32=검정, 3/16=금색 **4종만.** 1/4″ 는 **제외** |
| 4 | 팝업 미디어 | **GIF/영상 → 정지 사진으로 변경.** 구조만 먼저 만들고 파일은 나중에 |
| 5 | 테마 | **다크 + 앰버** (다른 페이지와 통일) |
| 6 | 분수 범위 | **1/64″ ~ 1/4″**, 1/64 간격 → **16개** |
| 7 | 기존 Huck 관계표 | **전부 삭제** |
| 8 | 번호 드릴 범위 *(v1.1)* | **#40 이상 제외 → #1 ~ #39 만** |
| 9 | 차트 모드 레이아웃 *(v1.1)* | 병렬 배치 폐기. **세로 한 줄 목록**으로 스크롤하며 전부 확인. 열은 **표기 · 인치 · 분수 · 메모** 4개 |

> **4번 변경의 효과:** GIF 대비 사진은 용량이 1/20~1/50 수준(300KB 이하)이라 초안에서 우려했던 저장소 용량·대역폭 문제가 **완전히 해소**됐다. 형식 변환 고민(MP4 권장 등)도 불필요해졌다.
>
> **8번 주의:** `#40` 은 AD3 3/32″ 리벳용 드릴이다. "40번 이상"을 문자 그대로 적용해 **#40 부터 잘라냈다.** 되살리려면 `info.html` 의 `const MAX_NO = 39;` 한 줄만 올리면 되고, `EXTRA["#40"]` 항목은 지우지 않고 남겨 뒀으므로 메모·클리코·사진이 그대로 복구된다.
>
> **9번 배경:** v1.0 의 N단 병렬 배치는 밀도가 높은 대신 `No. | Dia.` 2열밖에 담지 못했다. 메모를 표에서 바로 읽으려면 열이 필요하므로, **"스크롤해도 되니 밑으로 내리면서 다 본다"** 는 요구에 맞춰 단일 목록으로 전환했다.

## 3. 목표 / 비목표

### 목표
1. No.1~80 + 분수 1/64~1/4″ 를 **하나의 지름 순 표**로 통합한다.
2. 인치 소수 ↔ mm ↔ 근접 분수를 **동시에** 보여 환산 단계를 없앤다.
3. 모바일에서 **스크롤 최소화**로 전체를 훑을 수 있게 한다.
4. 항목별 **자유 메모 · 클리코 색 · 참고 사진**을 붙일 수 있는 구조를 만든다.
5. 사진 파일이 **하나도 없어도 표가 완전히 동작**해야 한다. (단계적 채우기)

### 비목표
- Letter drill, 탭 드릴, 나사 하부 구멍 표 (v2 이관)
- RPM·이송 계산
- Firebase 연동 / 사용자별 저장 — 읽기 전용 참조표
- 로그인 요구 — `divider.html` 과 동일하게 불필요

## 4. 핵심 설계 — 뷰 모드 2종

"한눈에 보기"와 "열 추가"는 서로 충돌한다. 열이 늘면 행이 길어지고, 압축하면 정보를 못 담는다. **같은 데이터를 두 가지로 표현**해 해결한다.

### 4-1. 차트 모드 (기본값) — 세로로 내려가며 전부 보기
`표기 · 인치 · 분수 · 메모` 4열의 **단일 세로 목록**. 위에서 아래로 스크롤하면 전부 지나간다.

```
표기   INCH    분수    메모
#1    .2280  15/64″   —
#2    .2210   7/32″   —
…
#11   .1910   3/16″   AD6 3/16″ 리벳 🖼
…
#30   .1285    1/8″   AD4 1/8″ 리벳 🖼
…
#39   .0995   3/32″   —
```

- `Number Size Drills` (39개) / `Fraction Size Drills` (16개) 두 블록으로 나뉜다.
- 표 헤더는 상태바·컨트롤 바 아래에 **고정(sticky)** 되어 스크롤 중에도 열 이름이 보인다.
- 사진이 있는 항목은 메모 뒤에 `🖼`.
- **아무 행이나 탭하면 하단 시트**가 올라와 mm · 클리코 · 사진까지 보여준다
  → 표에는 4열만 두고, 나머지는 시트로 넘긴다.
- 목록 폭은 760px로 제한해 넓은 화면에서 줄이 지나치게 길어지지 않게 한다.

| 화면 폭 | 한 화면 표시 행 | 전체 높이 |
|---------|:---------------:|-----------|
| 375px (폰) | 13행 | 약 3.2 화면 |
| 1280px | 20행 이상 | 약 2 화면 |

### 4-2. 상세 모드 — 열 전체
8열 세로 표. 검색·정렬·필터가 여기서 동작한다. 번호와 분수가 **지름 순으로 섞여** 표시되므로 "이 지름 근처에 뭐가 있나"를 바로 본다.

```
구분 │ 표기   │ inch  │ mm   │ 근접분수      │ 메모            │ 클리코  │ 사진
No.  │ #11    │ .1910 │ 4.85 │ 3/16″(+.0035) │ AD6 3/16″ 리벳  │ ● 금색  │ 🖼
No.  │ #12    │ .1890 │ 4.80 │ 3/16″(+.0015) │ —               │ —       │ —
Frac │ 3/16″  │ .1875 │ 4.76 │ —             │ —               │ —       │ —
No.  │ #13    │ .1850 │ 4.70 │ 3/16″(−.0025) │ —               │ —       │ —
```

모드 전환은 툴바 토글 한 번, 선택은 `localStorage` 에 저장된다.

## 5. 데이터 사양

### 5.1 행 — 총 55개

| 분류 | 개수 | 범위 | 비고 |
|------|:----:|------|------|
| Number drill | **39** | #1 (.2280) ~ **#39 (.0995)** | 제공 데이터. **ANSI 표준값과 전량 대조 완료.** #40~#80 은 `MAX_NO` 로 제외 |
| Fraction drill | **16** | 1/64″ (.0156) ~ 1/4″ (.2500) | 코드에서 `n/64` 로 생성 → 오타 불가 |

> 데이터 배열에는 **#80 까지 그대로 보존**돼 있고 `MAX_NO = 39` 로 잘라 쓴다. 숫자 하나만 바꾸면 범위가 되돌아온다.

### 5.2 열 — 8개

| # | 열 | 출처 | 차트 모드 | 상세 모드 | 폰(상세) |
|---|-----|------|:--------:|:--------:|:--------:|
| 1 | 구분 (No./Frac) | 자동 | — | ✅ | 숨김 |
| 2 | **표기** (`#30`, `1/8″`) | 자동 | **✅** | ✅ | ✅ |
| 3 | **소수 인치** | 데이터 | **✅** | ✅ | ✅ |
| 4 | mm | 자동 (×25.4) | 토글/시트 | ✅ | ✅ |
| 5 | **근접 분수** + 오차 | 자동 | **✅** (오차는 시트) | ✅ | 숨김 |
| 6 | **자유 메모** | 입력 | **✅** | ✅ | ✅ |
| 7 | 클리코 색 | 입력 | 시트 | ✅ | ✅ |
| 8 | 사진 | 파일 | 🖼 표시 | 🖼 버튼 | ✅ |

> 차트 모드의 인치 열은 `inch|mm` 토글로 전환된다(헤더도 `INCH` ↔ `MM` 으로 바뀜).

### 5.3 데이터 구조

`info.html` 안 인라인 JS. (외부 JSON `fetch` 는 `file://` 로 열 때 CORS 로 막히므로 인라인이 안전)

```js
const EXTRA = {
  "#40": { memo:"AD3 3/32″ 리벳", cleco:"silver", photo:"drill-40.jpg" },
  "#30": { memo:"AD4 1/8″ 리벳",  cleco:"copper", photo:"drill-30.jpg" },
  "#21": { memo:"AD5 5/32″ 리벳", cleco:"black",  photo:"drill-21.jpg" },
  "#11": { memo:"AD6 3/16″ 리벳", cleco:"brass",  photo:"drill-11.jpg" }
};
```

- 키는 표에 나오는 **표기와 동일**해야 한다. 분수는 `″` (U+2033) 사용.
- 필드는 전부 선택. 없는 항목은 표에 자동으로 표시되지 않는다.
- 초기 4개는 리벳 규격이 확정된 항목만 넣었다. **불확실한 값은 채우지 않았다** — 잘못된 드릴을 잡으면 소재를 버리기 때문.

## 6. 사진 팝업 사양

### 6.1 동작
1. 상세 모드의 `🖼` 버튼 또는 하단 시트의 `사진 보기` 를 누른다
2. 중앙 모달 + 배경 흐림, 제목(표기 · 메모) / 사진 / 설명(선택) 구성
3. 닫기: `✕` · 배경 탭 · `ESC`
4. 사진은 **모달을 여는 순간 처음 로드** → 초기 페이지 로딩과 무관
5. **파일이 없으면** 깨진 이미지 대신 "사진 준비 중입니다 + 넣어야 할 경로" 안내 카드

### 6.2 파일 규칙 (`assets/photos/`)

| 항목 | 권장 | 최대 |
|------|------|------|
| 형식 | `.jpg` (사진) / `.png` (도해) | `.webp` |
| 가로 해상도 | 1000~1400px | 1920px |
| 파일당 | **300KB 이하** | 1MB |
| 전체 합계 | 10MB 이하 | 30MB |

> 이 저장소는 이미 62MB 다. 폰 원본(4~8MB)을 그대로 올리면 열람이 느려지므로 리사이즈·압축 후 올린다. 자세한 절차는 `assets/photos/README.md`.

### 6.3 사진 추가 절차 (2단계)
1. 파일을 `assets/photos/` 에 넣는다
2. `info.html` 의 `EXTRA` 에 `photo:"파일명.jpg"` 한 줄을 적는다

## 7. 검색 · 필터 · 정렬

| 기능 | 동작 |
|------|------|
| 검색 | `30` · `.128` · `1/8` · `3.26` · `리벳` · `구리색` 전부 매칭 |
| **지름 역검색** | 숫자 입력 시 **최근접 드릴 3개**를 오차와 함께 상단에 표시. 누르면 상세로 이동 |
| 단위 해석 | 입력값 **1.0 이하 = inch, 초과 = mm** |
| 필터 칩 | 전체 / No. / 분수 / 메모 있음 / 사진 있음 |
| 정렬 | 지름 큰 순(기본) · 작은 순 · 번호 순 *(상세 모드 전용)* |
| 단위 토글 | inch ↔ mm (차트 모드 Dia. 열에 즉시 반영) |

**검증 예시**
- `3.2` 입력 → `1/8″(−.0010)` · `#30(+.0025)` · `#31(−.0060)`
- `1/8` 입력 → `1/8″ 일치` · `#30(+.0035)` · `#31(−.0050)`

## 8. 표기 규칙

| 항목 | 형식 | 예 |
|------|------|-----|
| 인치 | 소수 4자리, 앞 0 생략 | `.1285` |
| mm | 소수 2자리 | `3.26` |
| 근접 분수 | 1/64 스냅 + 기약분수 + 부호 오차 | `1/8″ (+.0035)` |
| 오차 부호 | 드릴이 분수보다 크면 `+` | `+`/`−` |

- 분수 행의 근접 분수는 자기 자신이므로 `—`.
- 숫자는 전부 고정폭(`IBM Plex Mono`)으로 자릿수를 맞춘다.

## 9. 화면 · 반응형

```
┌ 상태바   ● DRILL CHART · NUMBER / FRACTION            08:23:09
├ 툴바     [← 보드로]  드릴 사이즈 표   [96 / 96 개]
├ 컨트롤   [🔍 검색______________] [차트|상세] [inch|mm] [정렬 ▾]   ← sticky
│          (전체) (No.) (분수) (메모 있음) (사진 있음)
├ 최근접   최근접 드릴 — 입력 3.20mm …                    (검색 시에만)
├ 표       차트 모드(N단 병렬) 또는 상세 모드(8열)
└ 범례     ● 표시 의미 · 클리코 색 4종 · 단위 해석 규칙
      ┌ 하단 시트 (셀 탭) ┐   ┌ 사진 팝업 ┐
```

- **body 가로 스크롤 없음** — 375px 검증 완료
- 상태바·컨트롤 바 sticky. 표 헤더는 그 아래 높이에 맞춰 자동 정렬(`--sticky-top` 을 실제 높이에서 계산)
- 하단 시트: 폰은 바텀시트, ≥700px 는 중앙 모달
- 탭 영역 최소 34px

### 9.1 알려진 제약
**폰에서 상세 모드의 표 헤더는 고정되지 않는다.** 가로 스크롤 컨테이너(`overflow-x`) 안에서는 sticky 가 뷰포트에 붙지 않는 브라우저 동작 때문이다. 폰의 기본 경로는 차트 모드 + 하단 시트이므로 실사용 영향은 작다고 판단해 v1에서는 수용한다. → **v2에서 폰 상세 모드를 카드형으로 바꾸면 함께 해결된다** (§13).

## 14. 운영 메모

- **메모·클리코·사진 추가**는 `info.html` 의 `EXTRA` 한 곳만 고치면 된다. 표 구조나 렌더 코드는 건드릴 필요 없다. 메모는 차트 모드 표에 **바로 보인다.**
- **번호 범위 변경**은 `const MAX_NO = 39;` 한 줄. 올리면 작은 드릴이 되살아나고, 내리면 더 잘린다. 데이터 배열은 #80 까지 그대로 있다.
- 클리코 색은 현재 **4종(은색·구리색·검정·금색)** 만 정의돼 있다. 1/4″ 는 확인되지 않아 의도적으로 비워 뒀다 — 확정되면 `CLECO` 객체에 한 줄 추가하면 된다.
- 표의 지름 데이터(`NUMBER_DRILLS`)는 표준 규격이므로 수정할 일이 없다.
