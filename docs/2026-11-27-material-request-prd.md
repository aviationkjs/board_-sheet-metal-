## 1. 목적

작업자가 청구한 자재와 그 처리 여부를 **넘버 · 구분 · 공정 · PN · 수량 · 처리결과 · 날짜 · 신청자** 한 표로 모두가 실시간으로 본다.

## 2. 결정 사항

- 넘버 · 공정 · 단위: 자율 입력 (공정·단위는 이미 쓴 값을 자동완성으로 추천) — 11/27
- 담당자: 관리자가 회원 관리에서 지정 (`users/{id}.requestAdmin`, 영역당 한 명) + 주관리자(admin) — 11/27
- **신청자: 직접 입력** (자동완성 추천). 수정·취소 권한은 로그인한 등록 계정(`createdBy`) 기준 — 11/27 오후
- **처리결과: 미처리 → FMS / IR / B/S 중 선택** (담당자만). 접수·처리중·완료·반려 단계는 없앰 — 11/27 오후
- **구분 칸 추가: 성능 / 수명** (넘버 바로 뒤, 청구할 때 필수 선택) — 11/27 오후
- **담당자 알림: 보드판이 열려 있거나 뒤에 떠 있을 때 새 청구 폰 알림** (무료 방식) — 11/27 오후

## 3. 화면

- 대문 탭 줄: 공지 · 달력 · 스티커 | 자재소모 · 자재청구(미처리 수 배지)
- 툴바: 건수 · 미처리 수, 담당자 표시, 담당자에게만 `🔔 새 청구 알림 켜기`, `＋ 청구`
- 필터: 미처리(기본) / 전체 / FMS / IR / B/S 칩, 성능·수명 선택, 월 선택, 넘버·공정·PN·신청자 검색
- 표: 넘버 · 구분 · 공정 · PN · 수량 · 처리결과 · 날짜(M/D) · 신청자. 미처리가 위, 같은 묶음은 최근 청구가 위
- 행을 누르면 상세: 구분 · 공정 · PN · 수량 · 신청자 · 청구일시 · 등록 계정 · 처리자 · 처리일시 · 비고
- 폰(560px 미만)에서도 8칸이 가로 스크롤 없이 한 화면에 들어간다

## 4. 처리결과와 권한

`pending 미처리 → FMS | IR | BS(B/S)` — 담당자가 하나를 고르면 처리 끝. 잘못 골랐으면 미처리로 되돌릴 수 있다.

| 동작 | 작업자 | 담당자 | admin |
|------|:-:|:-:|:-:|
| 청구 등록 | O | O | O |
| 내가 등록한 청구 수정 · 취소 (미처리일 때만) | O | O | O |
| 처리결과 선택 (FMS / IR / B/S / 미처리) | – | O | O |
| 새 청구 폰 알림 | – | O | O |
| 담당자 지정 · 해제 (회원 관리) | – | – | O |
| 남의 청구 삭제 | – | – | O |

## 5. 데이터

```
materialRequests/items/{pushId}
  no, category(성능|수명), process, pn, qty, unit, requester(직접 입력), note,
  status: pending | FMS | IR | BS,
  createdBy(로그인 계정), createdAt, updatedAt, handler, handledAt
users/{id}/requestAdmin: true
```

로그(`logs`): `MATREQ_CREATE`, `MATREQ_UPDATE`, `MATREQ_UPDATE_STATUS`, `MATREQ_DELETE`.
이전 상태값(requested 등)으로 저장된 청구는 미처리로 보인다.

## 5-1. 알림 동작 (`matreq-notify.js`)

- 담당자·admin 이 보드판(대문 또는 자재청구 페이지)을 열어 두면, 새 청구가 들어올 때 폰 알림이 뜬다. 내가 올린 청구는 알리지 않는다.
- 처음 한 번 자재청구 페이지의 `🔔 새 청구 알림 켜기`를 눌러 허용해야 한다.
- 알림을 누르면 자재청구 페이지가 열린다 (`sw.js` notificationclick).
- 앱을 완전히 끈 상태에서도 오게 하려면 Firebase Blaze 요금제 + Cloud Functions + FCM 이 필요하다 (다음 단계).

## 6. 배포 체크

1. `database.rules.json`을 Firebase 콘솔 › Realtime Database › 규칙에 붙여넣고 **게시** (안 하면 저장은 되지만 값 검사가 빠짐)
2. 회원 관리에서 자재청구 담당자 지정 → 담당자 폰에서 자재청구 페이지 `🔔 새 청구 알림 켜기`
3. `sw.js` VERSION `v20261127-5` — 폰에서 앱을 한 번 다시 열면 새 페이지가 받아진다

## 7. 다음 단계 (선택)

- 처리결과에 받은 수량 기록 (부분 지급, 예: FMS 150/200)
- 같은 넘버로 등록한 PN 묶어 보기
