| 항목 | 내용 |
|------|------|
| 문서명 | 성능기골 스티커 보드 — 균등분할 계산기 |
| 버전 | v1.0 (초안) |
| 작성일 | 2026-08-13 |
| 대상 파일 | `divider.html` (신규), `index.html` (진입 버튼 추가) |
| 인프라 | GitHub Pages 정적 호스팅, 서버 없음, DB 사용 안 함(로컬 저장만) |

## 1. 배경

판금 작업에서 리벳/스크류 홀을 일렬로 뚫을 때, 작업자는 매번 **"전체 길이 ÷ 구간 수"** 를 손으로 계산하고 그 값을 자에 옮겨 하나씩 누적해서 찍는다. 이 과정에서 반복적으로 발생하는 문제:

- 나눗셈 결과가 대부분 무한소수(예: 6 ÷ 7 = 0.857142…)라 누적 표시 중 오차가 쌓인다.
- 인치 자는 눈금이 분수(1/16, 1/32)인데 계산 결과는 소수라 매번 환산이 필요하다.
- 구멍 개수와 구간 개수를 헷갈려 홀 1개가 남거나 모자란다. (**핵심 혼동 지점**)

이를 **"전체 구멍 개수 + 선 전체 길이"** 두 값만 넣으면 간격·각 구멍 위치·도면까지 자동으로 뽑아주는 계산기로 해결한다.

## 2. 목표 / 비목표

### 목표
1. **입력 2개(전체 구멍 개수 N, 전체 길이 L) → 간격 자동 계산.**
2. 계산 결과를 **소수 인치 / 분수 인치(자 눈금) / mm** 로 동시 제공.
3. 각 구멍의 **기준점(0)으로부터의 누적 위치**를 표로 제공 → 자를 한 번만 대고 전부 표시 가능(누적 오차 제거).
4. **평면선 위 구멍 배치를 SVG 도면으로 즉시 시각화** → 개수·양 끝 처리 오해 방지.
5. 리벳 지름 기준 **최소 피치 / 연거리 경고**로 잘못된 배치를 사전에 차단.
6. 현장 사용 환경 고려: 모바일 우선, 오프라인 동작, 로그인 불필요.

### 비목표
1. 2D 패턴(격자 배열), 원주 분할(볼트 서클)은 v1 범위 밖 → 확장 아이디어로 이관.
2. CAD 파일(DXF 등) 출력 없음.
3. Firebase 연동·계정별 저장 없음(v1은 `localStorage`만 사용, DB 규칙 변경 불필요).
4. 굽힘 여유(Bend Allowance)·전개도 계산 없음(별도 기능).

## 3. 용어 정의

| 용어 | 정의 |
|------|------|
| N (전체 구멍 개수) | 양 끝 구멍을 **포함한** 총 구멍 수 |
| L (전체 길이) | 첫 구멍 중심 ~ 마지막 구멍 중심까지의 거리 (기본 모드) |
| 구간 수 (Spaces) | 구멍 사이 간격의 개수 = **N − 1** |
| P (피치 / 간격) | 구멍 중심 간 거리 = **L ÷ (N − 1)** |
| 내부 구멍 | 양 끝을 제외하고 새로 표시해야 하는 구멍 = **N − 2** |
| ED (연거리, Edge Distance) | 소재 끝단 ~ 구멍 중심 거리 |
| D | 리벳/홀 지름 |

> **핵심**: 구멍 8개 → 구간 7개 → 내부에 새로 찍는 구멍 6개. 화면에서 이 세 숫자를 항상 같이 보여준다.

## 4. 계산 로직

### 4.1 모드 A — 중심 기준 (기본값)
> "첫 구멍과 마지막 구멍 위치는 이미 정해져 있고, 그 사이를 균등분할한다."

```
구간 수  S = N - 1
피치     P = L / S
i번째 구멍 위치 (i = 1..N):  x_i = L * (i - 1) / S      // 누적 곱셈 → 반올림 오차 누적 없음
내부 구멍 수 = N - 2
```

**사용자 제시 예시 검증 (N = 8, L = 6")**

| 항목 | 값 |
|------|-----|
| 구간 수 | 7 |
| 피치 P | 6 ÷ 7 = **0.8571"** (21.77 mm) |
| 분수 근사 (1/16) | 55/64 ≈ 0.8594" 기준, 1/16 스냅 시 13/16(0.8125") — 오차 큼 → 1/32 이상 권장 |
| 새로 표시할 내부 구멍 | **6개** ✅ (사용자 설명과 일치) |

| # | 위치(인치) | 위치(분수, 1/32 근사) | 위치(mm) |
|---|-----------|----------------------|----------|
| 1 | 0.0000 | 0 | 0.00 |
| 2 | 0.8571 | 27/32 | 21.77 |
| 3 | 1.7143 | 1‑23/32 | 43.54 |
| 4 | 2.5714 | 2‑9/16 | 65.31 |
| 5 | 3.4286 | 3‑7/16 | 87.09 |
| 6 | 4.2857 | 4‑9/32 | 108.86 |
| 7 | 5.1429 | 5‑5/32 | 130.63 |
| 8 | 6.0000 | 6 | 152.40 |

### 4.2 모드 B — 소재 전체 기준 (옵션)
> "소재 전체 길이만 알고, 양 끝 연거리부터 정해야 한다."

- **B‑1. 연거리 직접 입력**: ED를 입력 → `P = (L − 2·ED) / (N − 1)`, `x_i = ED + P·(i−1)`
- **B‑2. 완전 균등분할**: 끝 여백까지 동일 간격 → `P = L / (N + 1)`, `x_i = P·i`

모드는 라디오 버튼으로 전환하고, **각 모드마다 도면 하단에 어떤 구간을 나눈 것인지 치수선으로 표시**한다.

### 4.3 역계산 (보조 기능)
- **간격 고정 모드**: N 대신 원하는 피치 P를 입력 → `N = round(L / P) + 1`, 실제 피치 = `L / (N − 1)` 재계산 후 "요청 피치 대비 오차" 표기.

## 5. 입력 · 출력 사양

### 5.1 입력

| 필드 | 타입 | 기본값 | 검증 |
|------|------|--------|------|
| 전체 구멍 개수 N | 정수 | 8 | N ≥ 2, 정수, 최대 200 |
| 전체 길이 L | 실수 | 6 | L > 0, 최대 400 (inch) / 10000 (mm) |
| 단위 | inch / mm 토글 | inch | 전환 시 입력값 자동 환산 |
| 모드 | A / B‑1 / B‑2 | A | — |
| 연거리 ED | 실수 | — | 모드 B‑1에서만 활성, `2·ED < L` |
| 리벳 지름 D | 실수 | (비움) | 선택 입력. 입력 시 경고 검사 활성 |
| 분수 정밀도 | 1/16 · 1/32 · 1/64 | 1/32 | inch 모드에서만 노출 |

- **입력 형식 관용**: `3 1/2`, `3-1/2`, `7/8`, `3.5` 모두 인치 값으로 파싱한다(현장에서 분수로 말하고 쓰기 때문).
- 입력 즉시 재계산(디바운스 없이 `input` 이벤트), 버튼 클릭 불필요.

### 5.2 출력

1. **요약 카드 3종 (대형 숫자)**
   - `피치 P` — 소수 + 분수 병기 (예: `0.857"` / `≈ 27/32"`)
   - `구간 수` (= N−1)
   - `새로 표시할 구멍` (= N−2, 모드 A 기준)
2. **위치 표** — 번호 / 누적 위치(소수) / 누적 위치(분수) / 직전 구멍과의 간격
   - 표의 값은 **누적 합이 아니라 매번 원식으로 계산**(4.1의 `x_i`)하여 오차 누적을 방지.
   - 분수 열은 스냅된 값이므로 **스냅 오차(±)** 를 작은 글씨로 병기.
3. **SVG 도면** — 평면선 1개, 구멍 원 N개, 양 끝 구멍은 다른 색(기존 위치), 내부 구멍은 강조색(새로 표시할 것). 치수선에 P와 L 표기. 화면 폭에 맞춰 반응형, 구멍 20개 초과 시 번호 라벨은 5개 간격으로 솎아 표시.
4. **복사 버튼** — 위치 목록을 텍스트로 클립보드 복사(작업지시서·메모 붙여넣기용).

### 5.3 표기 규칙
- 소수: inch는 소수점 4자리, mm는 2자리.
- 분수 스냅: 선택 정밀도의 최근접 값. 스냅 오차가 `0.01"`를 넘으면 해당 값을 경고색으로 표시.
- 1 inch = 25.4 mm 고정.

## 6. 검증 · 경고 (리벳 지름 D 입력 시)

| 조건 | 등급 | 메시지 |
|------|------|--------|
| `P < 3D` | 위험(적색) | "피치가 최소 기준(3D)보다 좁습니다 — 소재 크랙 위험" |
| `3D ≤ P < 4D` | 주의(황색) | "일반 권장 범위(4D~6D) 미만입니다" |
| `P > 10D` | 주의(황색) | "피치가 넓습니다 — 실링/강도 요구 조건 확인" |
| `ED < 2D` (모드 B‑1) | 위험(적색) | "연거리가 최소 기준(2D) 미만입니다" |
| `ED > 4D` (모드 B‑1) | 주의(황색) | "연거리 권장 상한(4D) 초과" |

- 기준값은 코드 상단 상수(`MIN_PITCH_D = 3`, `REC_PITCH_D = 4`, `MIN_ED_D = 2`, `MAX_ED_D = 4`)로 분리해 추후 사내 기준에 맞춰 수정 가능하게 한다.
- **경고는 계산을 막지 않는다.** 값은 항상 표시하고 배지로만 알린다.

## 7. 예외 처리

| 상황 | 처리 |
|------|------|
| N < 2 | "구멍은 2개 이상이어야 합니다" — 결과 영역 비활성 |
| N = 2 | 정상. 피치 = L, 내부 구멍 0개, "양 끝만 표시" 안내 |
| L ≤ 0 또는 비어있음 | 결과 영역 비활성, 안내 문구 |
| N이 소수(2.5 등) | 자동 반올림 후 "정수로 보정됨" 안내 |
| 모드 B‑1에서 `2·ED ≥ L` | "연거리가 소재 길이보다 큽니다" — 결과 비활성 |
| 매우 큰 N (>200) | 표는 가상 스크롤 없이 200행 제한 + 안내 |

## 8. 화면 구성

기존 `remove_list.html` 의 **산업용 다크 테마 토큰(`--bg #16181c`, `--panel`, `--amber #ffb020`, IBM Plex Sans/Mono)** 을 그대로 재사용해 페이지 간 통일감을 유지한다.

```
┌ 상태바 (기존 statusbar 패턴, 좌: 페이지명 / 우: 시계)
├ 툴바 [← 뒤로]  균등분할 계산기   [inch|mm]
├ 입력 패널  ┌ 구멍 개수 N ┐ ┌ 전체 길이 L ┐ ┌ 리벳 지름 D(선택) ┐
│            모드: (•) 중심 기준  ( ) 연거리 입력  ( ) 완전 균등
├ 요약 카드  [ 피치 0.857" · 27/32 ] [ 구간 7 ] [ 새 구멍 6 ]
├ 경고 배지  (조건 충족 시)
├ SVG 도면   ○──●──●──●──●──●──●──○   (치수선 L, P)
└ 위치 표    # / 소수 / 분수 / 구간간격          [📋 복사]
```

- 모바일(≤600px): 입력 필드 2열, 요약 카드 가로 스크롤, 표는 `overflow-x:auto`.
- 숫자 입력은 `inputmode="decimal"` 로 모바일 숫자 키패드 유도.

## 9. 진입점 / 네비게이션

- `index.html` 헤더의 **더보기(⋯) 드롭다운**에 `📐 균등분할 계산기` 항목 추가 → `divider.html` 이동.
- `divider.html` 좌상단 [← 뒤로] 버튼으로 `index.html` 복귀 (기존 `.back` 버튼 패턴 재사용).
- **로그인 불필요** — 계산기는 개인 데이터를 다루지 않으므로 `auth.html` 리다이렉트를 적용하지 않는다. (기존 페이지들과 다른 유일한 예외이며, 의도된 결정)

## 10. 데이터 저장

- v1은 **Firebase 미사용**. 마지막 입력값(N, L, 단위, 모드, D, 분수 정밀도)만 `localStorage['dividerPrefs']`에 저장해 재방문 시 복원.
- DB 규칙(`database.rules.json`) 변경 없음.

## 11. 기술 스택

- **단일 HTML 파일** (`divider.html`) + 인라인 `<style>` / `<script>` — 기존 `remove_list.html`, `duty_roster.html` 과 동일한 구성 방식.
- 외부 라이브러리 없음. 도면은 **인라인 SVG 직접 생성**(CSP·GitHub Pages 안전, 오프라인 동작).
- 폰트만 Google Fonts(IBM Plex) 사용 — 기존 페이지와 동일.

## 13. 인수 조건 (Acceptance Criteria)

1. N = 8, L = 6 inch 입력 시 → 피치 `0.8571"`, 구간 `7`, 새로 표시할 구멍 `6`, 도면에 총 8개 구멍(양 끝 2 + 내부 6)이 그려진다.
2. 위치 표 마지막 행이 정확히 `6.0000"` 이다 (누적 오차 0).
3. 단위를 mm로 전환하면 즉시 `152.40 mm`, 피치 `21.77 mm` 로 바뀐다.
4. N = 2 입력 시 오류 없이 "양 끝만 표시(내부 구멍 0)" 로 동작한다.
5. N = 1 또는 L = 0 입력 시 결과 영역이 비활성화되고 안내 문구가 뜬다.
6. D = 0.25 입력 시 피치 0.8571 ÷ 0.25 = 3.43D → **주의(황색)** 배지가 뜬다.
7. 길이 입력란에 `6 1/2` 를 입력하면 6.5로 파싱된다.
8. 새로고침 후에도 마지막 입력값이 유지된다.
9. 375px 폭에서 가로 스크롤(body) 없이 모든 요소가 읽힌다.

## 14. 확장 아이디어 (v1 이후)

- **자 기울이기(대각선) 팁**: 6" 폭을 7등분해야 할 때 자를 비스듬히 놓아 0~7"를 걸치고 1"마다 찍는 현장 기법을, 입력값에 맞춰 "자를 X" 눈금까지 걸치고 Y 간격으로 표시하세요" 형태로 자동 안내.
- **원주 분할(볼트 서클)**: 지름 + 개수 → 각도 및 X/Y 좌표.
- **2D 격자 배열**: 가로·세로 동시 균등분할.
- **인쇄용 실척 템플릿**: A4 1:1 출력 후 소재에 대고 찍는 종이 지그.
- **PWA 오프라인 설치**: 격납고/현장 통신 불량 환경 대응.
- **계산 이력 공유**: 스티커 보드에 계산 결과를 카드로 붙이기(기존 `notes` 연동).

## 15. 확인 필요 사항

1. **기본 모드 확정** — 본 문서는 사용자 설명(8개·6인치 → 6개 표시)에 근거해 **모드 A(첫 구멍~마지막 구멍 중심 거리)** 를 기본값으로 잡았다. 만약 현장에서 L을 "소재 전체 길이"로 쓰는 경우가 더 많다면 기본값을 모드 B로 바꾼다.
2. **분수 기본 정밀도** — 1/32 로 가정. 현장 자 눈금이 1/16 위주라면 기본값 변경.
3. **리벳 기준값** — 최소 피치 3D / 권장 4D / 연거리 2D~4D 는 일반 항공 판금 관례값. 사내 기준서가 따로 있다면 §6 상수를 교체.
