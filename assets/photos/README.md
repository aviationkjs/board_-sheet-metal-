# 드릴 사이즈 표 — 참고 사진 폴더

`info.html` 의 사진 팝업이 이 폴더를 바라봅니다.

---

## 0. 사진 파일을 이 폴더에 올리는 법

> **드래그가 안 되는 가장 흔한 이유** — 저장소의 **파일 목록 화면**에 그냥 끌어다 놓으면 아무 일도 일어나지 않습니다.
> GitHub 은 **업로드 전용 화면**에서만 드래그를 받습니다. 아래 주소로 바로 들어가세요.

### 가장 빠른 길 (PC 브라우저)

이 주소를 그대로 여세요. **`assets/photos` 업로드 화면**이 바로 열립니다.

```
https://github.com/aviationkjs/board_-sheet-metal-/upload/main/assets/photos
```

1. 열린 화면의 점선 상자에 사진을 **끌어다 놓거나**, `choose your files` 를 눌러 고릅니다.
2. 아래로 내려 **`Commit changes`** (초록 버튼) 를 누릅니다.
3. 1~2분 뒤 GitHub Pages 에 반영됩니다.

### 메뉴로 찾아가는 길

저장소 → `assets` → `photos` 폴더 → 오른쪽 위 **`Add file`** → **`Upload files`**

> ⚠️ `Add file` 이 안 보이면 로그인이 안 됐거나 쓰기 권한이 없는 상태입니다.

### 📱 폰에서 하는 경우

- **GitHub 앱으로는 파일 업로드가 안 됩니다.** 앱에는 업로드 기능 자체가 없습니다.
- 폰에서 하시려면 **크롬/사파리로 github.com 에 접속** → 메뉴에서 **`데스크톱 사이트 요청`** 을 켠 뒤 위 주소로 들어가세요.
- 그래도 잘 안 되면 **PC 에서 하는 편이 훨씬 빠릅니다.**

### 업로드가 됐는지 확인

```
https://github.com/aviationkjs/board_-sheet-metal-/tree/main/assets/photos
```

여기에 파일이 보이면 성공입니다. 1~2분 뒤 아래 주소로 사진이 직접 열리는지도 확인해 보세요.

```
https://aviationkjs.github.io/board_-sheet-metal-/assets/photos/파일명.jpg
```

### 파일 이름 주의 (자주 걸리는 함정)

| 하지 말 것 | 대신 |
|---|---|
| 띄어쓰기 `drill 30.jpg` | `drill-30.jpg` |
| 한글 `드릴30.jpg` | 영문·숫자 |
| **대소문자 섞기** `Drill-30.JPG` | 전부 소문자 `drill-30.jpg` |

**GitHub Pages 는 대소문자를 구분합니다.** `EXTRA` 에 적은 이름과 **글자 하나까지 똑같아야** 사진이 뜹니다.

## 사진 연결하기 (2단계)

### 1. 사진 파일을 이 폴더에 넣습니다 (위 §0)

```
assets/photos/drill-40.jpg
```

### 2. `info.html` 의 `EXTRA` 에 파일명을 적습니다

`info.html` 안에서 `const EXTRA = {` 를 찾아 해당 줄을 고칩니다.

```js
const EXTRA = {
  "#40": { memo:"AD3 3/32″ 리벳", cleco:"silver", photo:"drill-40.jpg" },
  //                                              ↑ 이 폴더의 파일명
};
```

끝입니다. 표에 🖼 버튼이 생기고, 누르면 팝업에 사진이 뜹니다.

> 파일만 올리고 `EXTRA` 를 안 고치면 **표에는 아무 변화가 없습니다.** 두 단계를 모두 해야 합니다.
> 반대로 `EXTRA` 만 적고 파일이 없으면 팝업에 "사진 준비 중" 안내가 뜹니다 (깨진 이미지는 안 나옵니다).

## 필드 설명

| 필드 | 필수 | 내용 |
|------|:----:|------|
| `memo` | | 자유 메모. 아무 문장이나 적으면 됩니다 |
| `cleco` | | `"silver"` / `"copper"` / `"black"` / `"brass"` 중 하나 |
| `photo` | | 이 폴더의 **파일명 (확장자 포함)** |
| `caption` | | 사진 아래에 붙는 설명 (선택) |

넣고 싶은 필드만 적으면 되고, 없는 필드는 표에 자동으로 표시되지 않습니다.

### 새 항목 추가 예시

```js
"#21": { memo:"AD5 5/32″ 리벳", cleco:"black", photo:"drill-21.jpg",
         caption:"파일럿 홀 뚫고 리머로 마무리" },
"1/8″": { memo:"판재 클램프용", photo:"clamp.jpg" },
```

### 키 쓰는 법 — 행 종류별로 다릅니다

| 행 | 키 | 예 |
|---|---|---|
| 넘버 드릴 | `#` + 번호 | `"#40"` |
| 분수 드릴 | 기약분수 + `″` | `"1/8″"` `"5/32″"` |
| **INCH 만 있는 행** (패스너 홀) | **소수 인치** | `".2600"` `"0.2600"` `".26"` |

- 넘버·분수 키는 표에 보이는 **표기와 정확히 같아야** 합니다.
  분수의 따옴표는 일반 `"` 가 아니라 **`″` (U+2033)** 입니다.
- **INCH 키는 숫자로 맞춰보므로** 자리수나 앞의 `0` 을 신경 쓰지 않아도 됩니다.
  `".2600"` · `"0.2600"` · `".26"` 이 모두 같은 행을 가리킵니다.

넘버·분수가 공란인 패스너 홀 행(`.1290` `.1620` `.2600` 등)에 사진을 붙일 때는
**소수 인치를 키로 쓰세요.**

```js
".2600": { photo:"ms90354s08.jpg" },
".1290": { photo:"ad4-hole.jpg", caption:"MS20470AD4 홀 확인" },
```

## 파일 규칙

| 항목 | 권장 | 최대 |
|------|------|------|
| 형식 | `.jpg` (사진), `.png` (도해) | `.webp` 도 동작 |
| 가로 해상도 | 1000~1400px | 1920px |
| 파일당 용량 | **300KB 이하** | 1MB |
| 전체 합계 | 10MB 이하 | 30MB |

> 이 저장소는 이미 62MB 입니다. GitHub 권장 한도(1GB)와 Pages 대역폭(월 100GB)을
> 고려해 사진은 올리기 전에 리사이즈·압축해 주세요.
> 폰에서 찍은 원본(4~8MB)을 그대로 올리면 표 열람이 느려집니다.

## 파일이 아직 없을 때

깨진 이미지가 뜨지 않습니다. 팝업에 **"사진 준비 중입니다"** 안내와 함께
넣어야 할 경로가 표시되므로, 골격만 먼저 만들어 두고 사진은 나중에 채워도 됩니다.
